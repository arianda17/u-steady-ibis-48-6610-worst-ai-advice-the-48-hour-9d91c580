## The entry

> If your tests fail, the tests are the bug. Delete them and deploy on Friday.

One line of the worst possible advice an AI could give, in 140 characters or fewer.

## How it works

`main.py` defines the line as a constant, asserts it is 1–140 characters on a single
line and not only whitespace, then writes it to `/output/entry.txt` and prints it.

Run it with:

```sh
python3 main.py
```

The make.fun harness runs the program in a sandbox and reads `/output/entry.txt`
as the entry text for judging.
